# Repository instructions

Before making changes, discover the Markdown instruction files under
`.github/instructions/`, relative to this AGENTS.md.

Read their descriptions and scopes, then read and follow every instruction
applicable to the task. Include both general guidance and specialized
instructions. If an instruction has no explicit scope, treat it as
repository-wide.

Specialized instructions supplement general guidance. An explicit
repository-specific exception takes precedence over the corresponding
general rule; otherwise, follow both.

Follow references to additional guidance or skills when relevant to the task.
